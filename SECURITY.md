# Security policy

## Supported versions

Only the latest GitHub release is supported with security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature instead of opening a public issue. Include the affected version, reproduction steps, expected behavior, and potential impact.

## Scope

Distraction Blocker is a self-control aid, not a security boundary. Administrator-level bypasses and deliberate modification of user-writable configuration are outside its threat model.

Privilege escalation, unintended modification of hosts-file content outside the marked block, and bypasses available through the normal GUI during a locked session are considered security issues.
